# DAYBOOK — version rose pique-nique

Prototype statique d'un journal social visuel, redesigné dans une direction moderne, pastel et Pinterest :
- fond vichy blanc / rose pâle
- boutons pastel
- cartes arrondies et effet papier
- feed social + suggestions
- interface française
- publication locale avec prévisualisation de photos

## Déploiement

Cette version reste un prototype front-end. Les comptes, profils publics, stockage des photos, abonnements, likes et commentaires réels nécessiteront ensuite un backend.
